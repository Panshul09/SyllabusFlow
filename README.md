# A-Level Study Planner

A Streamlit-based study planner designed for A-Level students.

## Features

- Add subjects and topics
- Set exam dates
- Rate topic difficulty and importance
- Estimate study time
- Automatically generate a priority-based study schedule
- Mark topics as completed
- Track subject and overall progress
- Persist planner data using JSON

## Tech Stack

- Python
- Streamlit
- JSON
- Git
- GitHub

## How to Run

```bash
python -m streamlit run app.py
